КАДР ЗА КАДРОМ — ПЛАНИРОВЩИК ФОТОСЕРИЙ

Версия 1.2. Экспорт актуальной опубликованной версии от 02.11.2026.

Все файлы сайта находятся в корне архива. Для статического хостинга загрузите их в одну папку, сохранив названия. Сборка и установка зависимостей не нужны.

Главная страница — index.html. JavaScript использует модули, поэтому сайт нужно открывать через веб-сервер или хостинг, а не двойным щелчком по локальному HTML.

Возможности: девять редактируемых кадров, три референса (человек, локация, одежда), готовые промпты, сохранение и открытие проекта JSON.

Фотографии и настройки хранятся в браузере пользователя. Для переноса своей серии используйте кнопку «Сохранить проект» в планировщике. Персональные фотографии и проекты в этот архив не включены.

Создание этого архива не меняет доступ к исходному приватному сайту.
